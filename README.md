# Dayshape · v0.5

개인 일정·업무 관리: https://sunup00-hys.github.io/dayshape/

## 회원가입과 로그인

1. **계정 · 웹 저장 → 회원가입**에서 아이디, 비밀번호, 비밀번호 확인을 입력합니다.
2. 다음부터는 같은 아이디·비밀번호로 로그인합니다. 어느 기기에서든 해당 사용자의 일정·업무·회사 휴일을 불러옵니다.
3. 기존 연결 코드로 저장한 일정이 있다면 **회원가입할 때** ‘기존 연결 코드로 만든 일정이 있어요’를 펼쳐 코드를 입력합니다. 기존 항목·완료 기록을 그대로 계정에 연결하며, 전환 후 이전 코드는 사용할 수 없습니다.

아이디는 영문·숫자로 시작하는 4~32자(. _ - 허용), 대소문자를 구분하지 않습니다. 비밀번호는 12~128자이며 대소문자를 구분합니다. 현재 아이디·비밀번호 찾기는 지원하지 않습니다.

로그인 세션은 최대 24시간이며 현재 탭의 세션 저장소에만 보관합니다. 로그아웃하면 해당 세션을 서버에서도 폐기합니다. 비밀번호는 브라우저 저장소에 기록하지 않으며 서버에는 scrypt(N=32768,r=8,p=3)로 처리한 salted hash만 저장합니다. 세션 토큰도 서버에서는 SHA-256 해시로만 보관합니다.

일정·업무 데이터는 웹 서버에 저장하며 기기에 캐시나 오프라인 큐를 만들지 않습니다. 약 15초마다, 또는 화면으로 돌아올 때 최신 내용을 확인합니다. 오프라인 저장은 지원하지 않습니다. 동시 수정은 버전 충돌을 안내하여 다른 기기의 변경 내용을 덮어쓰지 않습니다.

구버전의 브라우저 데이터는 로그인 후 ‘기존 데이터 웹으로 옮기기’로 이전합니다. 서버에 원본대로 저장되었는지 확인한 뒤에만 기기 원본을 삭제합니다.

## 기능과 개발

월·주·일 캘린더, 주말 접기, 날짜별 + 등록, 반복 일정, D-day·중요도 강조, 미팅과 업무 구분, 단계별 납기, 회사 휴일, 한국 공휴일, 상세 미리보기, 표 보기, 엑셀·JSON 내보내기를 지원합니다. 미팅 팝업은 화면을 열어 둔 동안 표시됩니다.

- `npm test`
- `npm run build`
- `config.js`: 공개 API 주소만 포함합니다. 비밀번호·토큰·개인 연결 코드를 소스에 넣지 않습니다.
- `src/store.js`: 원격 저장, 재시도, 인증 만료, 충돌 방지, 브라우저 데이터 이전
- 전용 Sites/D1 서버에서 인증 세션의 사용자와 공간을 확인한 후 모든 읽기·쓰기 요청을 처리합니다. 요청 본문의 사용자 ID나 공간 ID를 신뢰하지 않습니다.

기존 코드 방식의 미전환 공간은 계속 보존됩니다. 연결 코드를 모르는 공간은 계정으로 가져올 수 없습니다. 회원가입 시 입력한 기존 공간은 하나의 계정만 소유할 수 있습니다.

참고: 한국 공휴일은 2026~2027년 공식 자료를 반영하며 이후 연도는 기존 규칙에 따른 예상입니다. 주말 보기 설정은 기기별로 저장하며, JSON/엑셀 다운로드는 사용자가 직접 요청한 백업입니다.
