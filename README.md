# Dayshape · v0.4

개인 일정·업무 관리: https://sunup00-hys.github.io/dayshape/

## 여러 기기에서 사용

1. ‘내 공간 · 웹 저장’에서 ‘처음이에요 · 내 공간 만들기’를 선택합니다.
2. 개인 연결 코드를 복사하여 안전한 곳에 보관합니다.
3. 다른 기기에서는 같은 연결 코드로 ‘내 공간 연결’을 선택합니다.

코드를 가진 사람은 해당 공간의 모든 데이터를 읽고 수정할 수 있습니다. 공개하거나 공유하지 마세요. 코드는 현재 탭의 세션에만 보관하며, 잃어버린 코드는 복구할 수 없습니다.
일정, 업무, 회사 휴일은 전용 웹 서버에 저장됩니다. 약 15초마다, 또는 화면으로 돌아올 때 새 내용을 확인합니다. 오프라인 저장은 지원하지 않습니다. 동시에 수정한 항목은 충돌 안내 후 새로고침하여 다시 수정합니다.

기존 버전의 브라우저 데이터는 연결 후 ‘기존 데이터 웹으로 옮기기’로 이전합니다. 서버에 정확하게 저장된 것을 확인한 뒤에만 기기 원본을 삭제합니다. 다른 브라우저에 있는 기존 데이터도 해당 브라우저에서 같은 코드로 연결한 후 옮겨 주세요.

## 기능

월·주·일 캘린더, 주말 접기, 날짜별 + 등록, 반복 설정, D-day·중요도 강조, 미팅과 업무 구분, 단계별 납기, 회사 휴일, 한국 공휴일, 상세 미리보기, 표 보기, 엑셀·JSON 내보내기를 지원합니다. 미팅 팝업은 화면을 열어 둔 동안 표시됩니다.

## 개발

- `npm test`
- `npm run build`
- `config.js`: 웹 저장 서버의 공개 API 주소만 포함. 비밀 연결 코드를 소스에 넣지 않습니다.
- `src/store.js`: 원격 저장, 재시도, 버전 충돌, 기존 데이터 이전
- 서버는 별도 Sites 프로젝트의 D1에 저장하며, 코드의 SHA-256 해시로 공간을 분리합니다.

기기에는 일정 데이터 캐시나 오프라인 큐를 만들지 않습니다. 주말 보기 설정은 기기별 UI 설정으로 보관합니다. JSON/엑셀 다운로드는 사용자가 직접 요청한 백업입니다.
